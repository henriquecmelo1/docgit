# docgit

Controle de versão estilo Git para Google Docs.

## Instalação

Na raiz do projeto, instale o pacote em modo editável:

```powershell
python -m pip install -e .
```

## Verificação

Liste os comandos disponíveis:

```powershell
docgit --help
```

Os comandos marcados como `[NOT IMPLEMENTED]` serão implementados nas próximas
fases do projeto.
